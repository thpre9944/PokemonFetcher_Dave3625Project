# PokemonFetcher_Dave3625Project
The purpose of this project is to search and learn about different pokemóns. See their stats and evolutions. And enjoy the beautiful artwork.
I created an Pokemón api fetcher that displays stats and sprites when a name is searched. I started this project my self in 2024 and used Claud to help finish and polish. I first made the api fetching and display of the pokemón sprite and name my self in 2024. I picked this project up again with the help of claud. 
With claud we added:
- favorites, can add pokemóns to a favorites list.
- toggle sprites(back side, pixel-art, shiny versions)
- previus and next buttons.
- made the searchbar auto complete names
- added stat and statbars. Resistance, strength and weakness stats.
- color coding for pokemón types and type names.

Reason i chose this project is because many of my friends like pokemón. I am not that interested except for that I think many of them are cool or beautiful to look at. I made this for my self to be able to check what pokemóns my friends are talking about and scroll through different evolutions that are cool to see. 

For me this solves a problem of feeling included in something my friends enjoy.
